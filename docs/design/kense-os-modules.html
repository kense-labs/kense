0x02 : 接入与控制

一把 Key 的承诺闭环：入口做准入与信任交换，五个共享模型决定配额、路由、计费、审计与凭据能否共用一条链。

Unified Gateway · 请求数 / 限流

Unified Gateway · 唯一入口与策略执行点。LLM / API / MCP / A2A 统一路由、限流、失败回退与快照准入；forward-auth 回注 subject / plane / org，主 Key 只在边缘出现一次。

Identity · —（信任根）

Identity · 一把 Key 的权威单点。库内只存 HMAC / argon2id 哈希与前缀；tenant → project → env 三层 Scope 决定计费、配额与发布边界；RFC 8693 换成 5–15 分钟、单服务 aud 的短时 SVID / JWT。

URN Registry · —（目录）

URN Registry · 所有能力先注册再暴露。注册时声明协议、计量单位、配额维度、SLO、scope 与审计等级；网关据此生成路由、SDK 与 OpenAPI，避免九套服务各写一遍鉴权。

Metering · credit（版本化汇率）

Metering · 每个请求产生唯一 meter 事件，带 event_id / trace_id / billing_parent；长任务预扣 → 心跳续扣 → 结束结算。账单链路完全异步，商业账本与 usage ledger 双轨且由架构测试强制不直连。

Audit · —（合规）

Audit · 每租户一条只追加哈希链，链头定期外部锚定。敏感动作先落审计再执行；审计员与管理员权限互斥，审计查询本身也产生事件。覆盖认证、授权、资源变更、数据访问、Agent 行为、计费预算、管理动作七类。

Vault · —（凭据）

Vault · 第三方凭据由 Vault 保管，主 Key 只存哈希。Scope = (org, project, env)；materialize 封存密文 → apply 按 scope × provider 激活 → revoke 终态，每步产生 receipt 并写入审计链。

0x03 : 服务层（供给侧依赖链）

IaaS → MaaS → TaaS → PaaS / AaaS → SaaS。下层向上层提供能力，上层向下层回报生产数据。

IaaS · vCPU·h / GPU·h / GB·月 / 出网 GB

IaaS · 异构加速卡事实与配额的持有者。节点 agent 零入站外连、心跳与租约上报事实；对外提供 VM / VPC / Volume / Image / Snapshot，租户 VPC 隔离、长生命周期。

MaaS · 输入/输出 token / 卡时 / 副本·秒

MaaS · 模型目录、制品分发、可解释放置与 OpenAI 兼容推理。platform 的 Rust 骨架由 catalog / gpu / scheduler / node-agent / distributor / state / inference 七个 crate 组成，推理层复用 kpower 的 /v1 与分布式服务。

TaaS · 训练 token / GPU·秒 / 评测次数

TaaS · 数据集、实验、Job、checkpoint、adapter 与评测门禁。Job 走 created → reserved → running → settled；评测与 Judge 复用同一套基准，供 adapter 上线与线上回归。生产轨迹与失败样本回流成新数据集与新 Benchmark。

PaaS · 构建分钟 / 请求数 / GB·s / 出网 GB

PaaS · Git → Build → Deploy → Rollback，产物不可变、Secrets 来自 Vault。发布使用与 MaaS / TaaS / Releases 共享的「版本 + 别名 + 流量权重」原语，回滚即别名翻转。项目 / 函数级弹性 0→N。

AaaS · actor·秒 / 唤醒次数 / 快照 GB·天

AaaS · Agent 运行时：单 actor 沙箱、会话、工具调用、挂起唤醒与检查点。沙箱零凭据，egress 网关只注入 secret_ref + version；沙箱 fail-closed，缺失宿主能力时拒绝降级为裸执行。

SaaS · 按有效结果条数；无结果不收费

SaaS · 构建在下面各层之上的产品表面。统一租户 schema、无状态，对外抽象为 Entity / Tool / Skill；按有效结果计费，无结果不产生账单。

0x04 : 开发者供应链

Actions 产出制品 → Packages 固化不可变版本 → Releases 用别名与流量权重灰度，把变更送进服务链并形成训练回流闭环。

Actions · runner·分钟 / 并发数

Actions · 事件触发的 Workflow（push / PR / schedule / 评测完成 / 训练完成 / 告警），托管 CPU 与 GPU 两种 Runner，Secrets 复用身份平面。产出构建产物给 Packages、触发 Releases，并可调用 TaaS 训练、MaaS 评测。

Packages · GB·月 / 拉取次数

Packages · OCI / ORAS 制品仓库：容器镜像、模型权重、LoRA adapter、数据集、Agent bundle、MCP server 包。版本不可变，附 Attestation 与 SBOM、签名验签，按命名空间与保留策略治理。

Releases · 发布次数 / 灰度流量

Releases · Release / Channel（canary、prod）/ Environment。灰度比例、健康检查门禁、一键回滚、变更记录与审计；把 MaaS 的 adapter 版本、PaaS 部署、AaaS actor 模板统一成一次可回滚发布。

0x05 : 资源底座

异构算力池只接受调度声明，不直接对租户暴露；控制面声明意图，资源池执行事实。

Heterogeneous Resource Pool · 容量由 IaaS 计量

Heterogeneous Resource Pool · 异构算力底座：NVIDIA / AMD / Ascend / PPU / Hygon / Apple 与云厂商。GPU / NPU 设备事实与显存、CPU / RDMA 主机网络、对象存储与镜像缓存。控制面声明放置意图，资源池执行事实，不对租户直接暴露。
