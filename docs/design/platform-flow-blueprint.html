元素用法视觉规则
处理节点一个动作 / 一次转换墨黑圆角矩形 rx=8–10，白字居中两行，等宽 14–15px
多级处理节点内部有分层或子步骤黑标题块 + 白底表格行，行间细线，右侧列阶段名
决策门PASS / FAIL 分流陶土橙菱形，白字；上方标 LINT_CHECK 类门禁名
失败 / 补偿节点拒绝、回滚、重试陶土橙圆角矩形，白字；配循环箭头表示回退
成功终点提交、落盘、执行墨黑圆角矩形，右上标 #141413 :
连线主干与分支1.2–1.4px 墨线，直角折线，开放 V 形箭头，无填充
文字仅节点内文字与必要的分支标签（FAIL / PASS）不加序号、动作名、页眉、页脚等装饰性小字；节点内 12–14px，分支标签 12px
装饰结构性的虚线框、连接虚线与循环箭头不使用四角括号、虚线角标、小圆点列等纯装饰；不抢主体

字体：ui-monospace, SFMono-Regular, Menlo, Consolas　·　节点内文字只有 400 / 500 两档字重　·　不用渐变、阴影、圆点网格。

REUSE NOTES / 复用说明

两张图共用同一套 <defs> 箭头与样式；新增流程时复制节点组，改节点文案与坐标即可。

场景替换方式

决策改成三分支菱形下方再加一条 M340 502 L340 566 的中路，用 PARTIAL 标注。
导出浏览器直接打印为 PDF（已加 @media print），或把单个 <svg> 另存为 .svg 供文档引用。
